XGBoost expliqué simplement

eXtreme Gradient Boosting — le moteur du modèle Wazuh AI Filter

1. Le principe : des correcteurs en série

XGBoost, c'est une bande d'arbres de décision qui bossent en équipe. Mais pas en parallèle (random forest) : en série. Chaque nouvel arbre apprend des erreurs du précédent.

Au début, le modèle prédit au hasard (0.3). Il compare avec la vraie valeur (0.5) et calcule l'erreur. L'arbre suivant apprend à corriger cette erreur. Et ainsi de suite, jusqu'à 300 arbres dans notre cas.

Prediction finale = Arbre1 + Arbre2 + Arbre3 + ... + Arbre300 Avec notre labo : 300 arbres, profondeur max = 6 niveaux

2. À quoi ressemble un arbre ?

Chaque arbre prend une alerte en entrée et la fait descendre à travers des questions oui/non jusqu'à une feuille qui donne un score.

Exemple concret : une alerte arrive. L'arbre regarde d'abord si count_rule_15min > 150 (beaucoup d'alertes de ce type en peu de temps ?). Si oui, il descend à droite et check l'IP source. Si l'IP attaque aussi beaucoup → score TP = +0.25. Sinon, il regarde d'autres indices.

4. XGBoost vs les autres méthodes

MéthodeNotre RecallNotre AUCPourquoi XGBoost gagne
Régression logistique~85%~0.95

XGBoost96.3%0.999Gère les déséquilibres (28x plus de FP), apprend les motifs complexes de répétition

XGBoost est le meilleur pour ce cas parce que :

  • Il gère naturellement les données déséquilibrées (scale_pos_weight)
  • Il capture les interactions complexes entre features (ex: heure + IP + règle)
  • Il passe à l'échelle : 300 arbres, 36 features, 57 000 alertes → quelques secondes d'entraînement
  • Les prédictions sont rapides : ~100 alertes/seconde en temps réel

5. Résultat concret sur le labo

Quand une alerte Wazuh arrive, le modèle XGBoost :

  1. Extrait les 36 features de l'alerte
  2. Les fait passer à travers les 300 arbres
  3. Additionne les scores de chaque arbre → un score final entre 0 et 1
  4. Si score > 0.5 : c'est une attaque (TP), l'alerte n'est pas filtrée
  5. Si score < 0.5 : c'est du bruit (FP), l'alerte peut être ignorée

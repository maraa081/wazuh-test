Détection d'intrusion avec Machine Learning

Labo Wazuh + Suricata + XGBoost — Maxime Lazurka

Le problème

Wazuh génère des milliers d'alertes par jour. 80% sont des faux positifs. Un administrateur passe son temps à trier au lieu de répondre aux vraies attaques.

Le labo

3 machines virtuelles sur un PC portable :

  • Cible (Ubuntu 22.04) — Suricata en écoute, Wazuh Agent, Docker
  • Manager (Ubuntu 24.04) — Wazuh, modèle XGBoost, inférence temps réel
  • Attaquant (ParrotOS) — nmap, hydra, hping3

Comment ça marche

Suricata surveille le réseau. Quand il détecte quelque chose, l'alerte remonte dans Wazuh. Un modèle XGBoost analyse chaque alerte et décide si c'est une vraie attaque (TP) ou un faux positif (FP). Le résultat s'affiche dans le dashboard Wazuh. Le tout en temps réel, sans intervention humaine.

Ce qui a été fait

  • Infrastructure automatisée : les 3 VMs se parlent sans intervention
  • Pipeline ML complet : génération d'attaques → collecte → entraînement → inférence
  • Modèle XGBoost entraîné sur le trafic réel du labo
  • Dashboard Wazuh avec les scores ML en temps réel
  • Synchronisation automatique des prédictions dans OpenSearch

🎯 Pipeline ML (5 étapes)

01_collect_alerts.py — Collecte les alertes depuis alerts.json au format JSONL
python3 pipeline/01_collect_alerts.py --days 1
02_label_dataset.py — Labellise les alertes en TP/FP à partir des fenêtres de campagne (ParrotOS + Docker)
python3 pipeline/02_label_dataset.py --alerts alerts.jsonl --campaign campaign.csv
03_feature_engineering.py — Extrait 36 features (temporelles, fréquence, IP, one-hot rules)
python3 pipeline/03_feature_engineering.py --input dataset_labeled.csv
04_train_model.py — Entraîne XGBoost avec scale_pos_weight, early stopping
python3 pipeline/04_train_model.py --input features.csv
05_evaluate_model.py — Évalue avec SHAP, courbes, threshold tuning
python3 pipeline/05_evaluate_model.py --input features.csv --model model.json

Detection d intrusion avec Machine Learning

Labo Wazuh + Suricata + XGBoost — Maxime Lazurka

Le probleme

Wazuh genere des milliers d alertes par jour. 80% sont des faux positifs. Un administrateur passe son temps a trier au lieu de repondre aux vraies attaques.

Le labo

3 machines virtuelles sur un PC portable :

  • Cible (Ubuntu 22.04) — Suricata en ecoute, Wazuh Agent, Docker
  • Manager (Ubuntu 24.04) — Wazuh, modele XGBoost, inference temps reel
  • Attaquant (ParrotOS) — nmap, hydra, hping3

Comment ca marche

Suricata surveille le reseau. Quand il detecte quelque chose, l alerte remonte dans Wazuh. Un modele XGBoost analyse chaque alerte et decide si c est une vraie attaque (TP) ou un faux positif (FP). Le resultat s affiche dans le dashboard Wazuh. Le tout en temps reel, sans intervention humaine.

Ce qui a ete fait

Ce qui reste a faire
